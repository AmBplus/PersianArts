## کتابخانهٔ طراحی، نه ویترین نمونه‌های مصنوعی

تمام مدل‌های منحصربه‌فرد منابع معرفی‌شده را در دو بخش جدا می‌بینید:

**طرح‌های آماده + پرامپت:** دستورهای شات‌کرافت، ۱۵ سبک مستقل `mg-styles-15`، الگوهای `video-talkcraft` و `anything2explainer`. مدل‌های چندگانهٔ هر طرح در پنل مدل‌ها قابل‌انتخاب‌اند. متن و دستور فارسی در کنار لینکِ دستور اصلی قابل کپی است.

**کامپوننت‌ها:** الگوهای حرکت پیوستهٔ `onetake`، فونت‌های آزاد فارسی، چهار مدل قلم خود پروژه، و کتابخانهٔ صوتی اصلی **۵ قطعه موسیقی و ۱۴۹ افکت صوتی** شات‌کرافت که بر اساس منبع و مجوز واقعی دسته‌بندی شده‌اند.

کتابخانه امکان جست‌وجو، فیلتر **منبع خاص**، دسته، تگ و نام مدل را دارد. هیچ سقف مصنوعی دو مدل در هر دسته وجود ندارد. فقط مواردی با هویت منبع دقیقاً یکسان حذف می‌شوند.

### وضعیت بازبینی ۱۳ اکتبر ۲۰۲۶ (تصمیم مالک)

الزام «تأیید رندر وفادار» و بررسی مجوز برای انتشار **برداشته شد**. رندرهای پیشین و منابع جدید (از جمله مراجع ویدیتور) بدون گیت وفاداری/مجوز وارد کتابخانه می‌شوند. نگاشت متن روی تصویر و پروندهٔ منشأ صرفاً به‌عنوان اطلاعات تکمیلی حفظ می‌شود.

پرامپت‌های اصلی چینی/انگلیسی ترجمه یا خلاصه نمی‌شوند. آماده نبودن رندر یا نبودن دستور اصلی به‌صراحت نمایش داده می‌شود؛ نمونهٔ ساختگی جانشین مرجع نمی‌شود.

### صدای منابع

فهرست صدای اصلی، منبع موسیقی، نام اثر، هنرمند (درصورت وجود) و لینک نمونهٔ اصلی را نشان می‌دهد. **چهار موسیقی و ۱۴۴ افکت** دارای URL ثبت‌شده‌اند.

فایل‌های Mixkit در پروژه‌های نهایی قابل استفاده‌اند. برای جزئیات، [مشخصات منابع](https://github.com/Vincentwei1021/video-shotcraft/blob/main/assets/audio/ATTRIBUTION.md) و [مجوزهای Mixkit](https://mixkit.co/license/) را ببینید.

## نحوهٔ اجرا

```bash
python3 -m http.server 8080
# http://localhost:8080/library/
```

برای توسعهٔ موتور خطاطی:

```bash
cd skills/anidoodle/engine
npm ci
node tools/persian-qa.mjs
```
