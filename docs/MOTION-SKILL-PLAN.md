# طرح اسکیل موشن‌گرافیک PersianArts

> سند طراحی و نقشهٔ راه. نسخهٔ ۱ — ۲۰ مهر ۱۴۰۵ (۱۲ اکتبر ۲۰۲۶).
> وضعیت: **فاز ۰ (اسکلت) در حال ساخت.** هر تغییر در قرارداد اصلی اینجا ثبت شود.

## ۱. هدف

مالک پروژه اسکیل را نصب می‌کند و می‌گوید: «یک موشن‌گرافیک آموزشی ۴۵ ثانیه‌ای دربارهٔ X با این مشخصات می‌خواهم».
اسکیل یک فیلم **مناسب و حرفه‌ای** تحویل می‌دهد: فارسی درست، طراحی یکدست، موسیقی هماهنگ و بدون حالت اسلایدشو.
این باید حتی وقتی کار با یک مدل ضعیف‌تر (Haiku یا Sonnet) انجام می‌شود هم اتفاق بیفتد.

### استعارهٔ اصلی: آشپزخانه

| آشپزخانه | در اسکیل |
|---|---|
| مواد اولیهٔ باکیفیت | **ماده‌ها (ingredients):** پس‌زمینه، افکت متن، چیدمان، عنصر، دوربین، انتقال، تزئین. همه تم‌پذیر و پارامتری‌اند. |
| ادویه و چاشنی | **تم‌ها، فونت‌ها، کتابخانهٔ موسیقی (با نقشهٔ ضرب) و کتابخانهٔ SFX** |
| دفتر دستور غذا | **دستورها (recipes):** فیلم‌های نمونه که نشان می‌دهند ماده‌ها چطور خوب ترکیب می‌شوند. برای یادگرفتن‌اند، نه کپی کردن. |
| آشپز | **مدل.** می‌تواند دستور تازه بسازد، از دستورها ایده بگیرد، یا مادهٔ تازه با خودش بیاورد. |
| ذائقه و استاندارد آشپزخانه | **قواعد:** فارسی، ضد اسلایدشو، اصول طراحی، و **دروازه‌های کیفیت** که جلوی غذای خراب را می‌گیرند. |

قاعدهٔ طلایی: **ماده‌ها «سازوکار و کوریوگرافی» هستند، نه «ظاهر».**
ظاهر (رنگ، فونت، بافت) همیشه از تم همان فیلم می‌آید. پس ترکیب ماده‌های مختلف خودکار یکدست می‌شود
و دو فیلم با ماده‌های مشترک شبیه هم نمی‌شوند.

node_modules هم یک بار در engine نصب می‌شود.

### ۳.۱ قرارداد تم (`theme.json`)

هیچ ماده‌ای رنگ hex یا اسم فونت را مستقیم نمی‌نویسد. فقط نقش‌ها را می‌خواند:

- **رنگ:** `bg`، `bgAlt`، `surface`، `ink`، `inkMuted`، `accent`، `accent2`، `line`، `glow`
- **فونت:** `display`، `body`، `numeric`، `ornament`، و به‌ازای هر فونت: وزن‌ها، `lineHeight` امن (مثلاً نستعلیق ≥۲.۴)، و `perLetterSafe: false`
- **مقیاس تایپ:** `scale` (مثلاً نسبت چهارم کامل)، اندازه‌های `hero`، `title`، `body`، `caption`
- **شخصیت حرکت:** `enter` و `exit` (منحنی bezier + مدت)، `spring` (حداکثر overshoot)، `stagger`، `breath` (زوم ۱.۰۰ تا ۱.۰۴)
- **بافت:** `grain`، `paper`، یا `none`، همراه با «دلیل فیزیکی»
- **صدا:** خانوادهٔ SFX ترجیحی، مثلاً `paper`، `glass` یا `mech`

تم‌های آماده نقطهٔ شروع‌اند. آشپز می‌تواند تم تازه بسازد، ولی اعتبارسنج (کنتراست، تعداد فونت، پوشش حروف) آن را بررسی می‌کند.

### ۳.۲ قرارداد ماده (`meta.ts` + کامپوننت)

```ts
export const meta = defineIngredient({
  id: 'text.paper-cut-words',          // <لایه>.<نام>
  layer: 'text',                        // background|layout|text|element|camera|transition|accent
  derivedFrom: 'shotcraft/typography/paper-title-card',
  purpose: 'عنوان گرم و دستی؛ هر کلمه یک تکه کاغذ',
  goodFor: ['title', 'chapter'],  avoidFor: ['dense-info'],
  energy: 2, mood: ['warm', 'crafted'],
  duration: { min: 45, ideal: 90, max: 150 },          // فریم در ۳۰fps
  slots: z.object({ words: z.array(faWord(12)).min(1).max(4) }),
  knobs: z.object({ tilt: z.number().min(0).max(6).default(3), direction: rtlDir }),
  events: ['land', 'settle'],            // لحظه‌های نام‌دار برای ضرب و SFX
  sfx: { land: 'paper.slap' },
  locked: ['ease.enter', 'stagger.ratio'],              // جزو هویت ماده؛ تغییر نکند
  fa: { perLetter: false, needsMaskSlack: true },
});
```

- **قفل‌شده:** کوریوگرافی و نسبت‌های زمانی. این هویت ماده است.
- **آزاد:** همهٔ متن‌ها و داده‌ها (slots)؛ تنظیم‌ها در بازهٔ مجاز (knobs)؛ و ظاهر که از تم می‌آید.
- **پیش‌فرض‌ها:** با props پیش‌فرض و «تم مرجع»، ماده باید **همان فریم‌های کارت تأییدشده** را بدهد. این را مقایسهٔ پیکسلی چک می‌کند و تبدیل را برای مدل ارزان قابل سنجش می‌کند.

### ۳.۳ پارتیتور فیلم (`film.json`): تنها منبع حقیقت

```json
{
  "fps": 30, "size": [1920, 1080], "theme": "themes/navy-scholar.json",
  "music": { "track": "library/music/xxx.json", "edits": [{"from": "bar 1", "to": "bar 16"}] },
  "scenes": [
    { "id": "s1", "at": "bar 1", "until": "bar 5",
      "purpose": "قلاب: سؤال اصلی", "primarySubject": "typographic-question",
      "layers": [
        { "use": "background.dot-field-wave", "knobs": {"density": 0.4} },
        { "use": "text.paper-cut-words", "slots": {"words": ["چرا","آسمان","آبی‌ست؟"]},
          "at": "bar 1 beat 3", "events": {"land": "bar 2 beat 1"} }
      ],
      "transition": { "use": "transition.one-shape-carry", "meaning": "همان موضوع ادامه دارد" } }
  ],
  "hits": [ { "at": "bar 9 beat 1", "sfx": "impact.soft", "label": "عدد کلیدی" } ]
}
```

- زمان‌ها به زبان موسیقی نوشته می‌شوند (`bar` و `beat`) و روی **خط زمانی فیلمِ ویرایش‌شده** حساب می‌شوند؛ `music.edits[]` به میزان‌های قطعهٔ اصلی اشاره می‌کند. فیلم بدون موسیقی با ثانیه (`"12.5s"`) زمان‌بندی می‌شود. موتور آن‌ها را از روی نقشهٔ ضرب به فریم تبدیل می‌کند. `from={1464}` دستی دیگر وجود ندارد.
- SFX خودکار از `events` ماده‌ها ساخته می‌شوند، به‌علاوهٔ `hits` دستی. صدا و تصویر از یک فایل می‌خوانند.
- `primarySubject` و `purpose` اجباری‌اند. بازبین تمایز صحنه‌ها و خطر اسلایدشو را از همین‌ها می‌سنجد.

### ۳.۴ کتابخانهٔ موسیقی و SFX

- هر قطعه یک فایل همراه JSON دارد که `pa music add` می‌سازد: BPM برازش‌شده، فاز، میزان‌ها، بخش‌ها (intro، build، drop، outro)، منحنی انرژی، کلید و مایه، دستگاه (اگر معلوم باشد)، حس، و نقاط برش امن.
- **قانون دانا:** یک فیلم، یک قطعه. کوتاه کردن فقط داخل همان قطعه و سر مرز جمله یا میزان. ترکیب دو آهنگ فقط با سکوت یا ضربهٔ قطع عمدی، و نیازمند تأیید مالک.
- SFX ها بر اساس رویداد دسته‌بندی شده‌اند: `whoosh`، `pop`، `land`، `impact`، `riser`، `tick`، `paper`، `glass`، ... هم‌چنین `persian-sound` (سنتز) برای ساخت افکت وقتی چیزی موجود نیست.

## ۴. مراحل تولید (کارگردان هر مرحله)

| # | مرحله | خروجی | دروازه |
|---|---|---|---|
| ۰ | **پذیرش (intake)** | `brief.json`: پیام، مخاطب، مدت، نسبت تصویر، متن‌ها، برند، محل انتشار، موسیقی، و حالت کار | فقط جاهای خالی واقعی پرسیده می‌شود |
| ۱ | **جهت هنری** | `direction.md`: خوانش طراحی، سه پیچ، تم، یک «امضای بصری»، ضدالگوها؛ به‌علاوهٔ ۳ استایل‌فریم | ✋ تأیید مالک |
| ۲ | **موسیقی اول** | انتخاب قطعه + نقشهٔ ضرب + نقشهٔ بخش‌ها روی میزان | ✋ تأیید مالک (با گوش دادن) |
| ۳ | **استوری‌بورد** | `film.json` پیش‌نویس: صحنه‌ها روی میزان‌ها، ماده‌های هر لایه، `purpose` و `primarySubject`؛ امتیاز اسلایدشو؛ و انیماتیک خام | ✋ تأیید مالک |
| ۴ | **آشپزی (ساخت)** | ترکیب ماده‌ها؛ ساخت ماده یا صحنهٔ تازه در `scenes/` در صورت نیاز؛ رندر استیل در لحظه‌های کلیدی | خودکار + اعتبارسنج |
| ۵ | **صدا** | SFX از رویدادها، میکس و ducking، loudness ‎-14 LUFS / ≤‎-1.5 dBTP، تست همگامی | خودکار + سنجش عددی |
| ۶ | **بازبینی** | نقد ۸ معیاره (حداقل ۳ دور تا نمرهٔ ≥۸)، سپس **بازبین بی‌طرف** (subagent بدون دسترسی به استدلال سازنده) | سازنده خودش را تأیید نمی‌کند |
| ۷ | **تحویل** | MP4 نهایی (با و بدون موسیقی)، پوستر، گزارش، و ثبت تصمیم‌ها | ✋ تأیید مالک |

**دو حالت کار** (مثل shotcraft):
- **هم‌آفرینی:** دروازه‌های ✋ فعال‌اند. پیش‌فرض است.
- **خودکار:** دروازه‌ها حذف می‌شوند، ولی تصمیم‌ها ثبت می‌شوند. فقط با درخواست صریح.

روایت فارسی (TTS)، زیرنویس، جست‌وجو و دانلود موسیقی، تحلیل ویدیوی مرجع، و QA تصویری.
اگر تنظیم نشده باشد، اسکیل بدون آن هم کامل کار می‌کند.

## ۶. دروازه‌های کیفیت (چه چیزی «غذای خراب» است)

**فنی** (خودکار، مسدودکننده):
- لینتر فارسی بدون خطا
- هیچ letter-spacing یا per-letter box روی فارسی (مگر با ابزار shaped)
- پوشش کامل حروف در فونت انتخابی
- سرریز متن صفر
- کنتراست متن ≥ ۴.۵
- حداکثر ۲ خانوادهٔ فونت
- برش‌ها ≤ ۳ فریم از ضرب
- loudness در محدوده

**طراحی** (نقد، باید به ≥۸ برسد):
1. سلسله‌مراتب و یک قهرمان در هر فریم
2. یکدستی با تم و جهت هنری
3. تمایز صحنه‌ها (موضوع اصلی هیچ دو صحنهٔ پشت‌سرهمی یکی نباشد)
4. ریتم و منحنی انرژی
5. هماهنگی با موسیقی
6. کیفیت فارسی
7. فضای خالی و خوانایی
8. «آیا این فیلم می‌توانست مال هر موضوع دیگری باشد؟» (اگر بله، شکست)

**امتیاز خطر اسلایدشو** (برگرفته از OpenMontage، با بومی‌سازی):
تکرار چیدمان، تزئین بی‌هدف، حرکت بی‌دلیل، صحنهٔ بی‌قصد، تکیهٔ بیش از حد به کارت متن، و fade بین صحنه‌ها.
