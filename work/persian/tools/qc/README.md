# contact.mjs — برگهٔ بازبینی فیلم

هدف: قبل از تحویل، فیلم را **به‌صورت تصویر** ببینیم، نه توصیف.

```bash
node work/persian/tools/qc/contact.mjs <frames-dir|video.mp4> --out out/qc --at 8.5 --n 24
```

خروجی‌ها در `--out`:

| فایل | چیست |
|---|---|
| `sheet.jpg` | ۲۴ فریم پخش‌شده روی کل فیلم (کاشی ۶×۴) — ریتم و تکرار را نشان می‌دهد |
| `strip.jpg` | ۱۲ فریم حول لحظهٔ `--at` — برای شکار پرش/لرزش/تکرار |
| `phone.jpg` | همان قاب‌ها با عرض ۳۶۰px — تست واقعی خوانایی روی موبایل |
| `review.json` | زمان دقیق هر کاشی + روبریک ۷ محوری + قاعدهٔ پذیرش |

روبریک (هر کدام ۱–۱۰):

۱. **هوک** — چیزی جالب در ۲ ثانیهٔ اول
۲. **خوانایی در ۳۶۰px** — پیام روی موبایل زنده بماند
۳. **کیفیت موشن** — بدون فریم مرده، بدون drift خطی، هر حرکت یک وظیفه دارد
۴. **تنوع** — هر ۲–۴ ثانیه چیز تازه
۵. **ترکیب‌بندی** — یک قهرمان در هر قاب، بدون کروم صفحه
۶. **دقت** — رنگ برند، اعداد واقعی، فارسی درست
۷. **سینک** — تصویر و صدا با هم می‌نشینند

**قاعده:** هیچ محوری زیر ۸ ⇒ فیلم تحویل نمی‌شود. سه ایراد بدترین را با زمان و شمارهٔ کاشی بنویس، اصلاح کن، دوباره بساز.

مرجع بصری: `work/persian/reference-motion/index.html` (۷۱ مرجع حرفه‌ای با منبع هر فایل).
اعداد سنجش انرژی موشن: `work/persian/tools/gates/motion-energy.mjs` — **تشخیصی**، آستانه‌ها پیش‌فرض خاموش‌اند (به‌دلیل یافتهٔ کالیبراسیون در `docs/motion/MOTION-METRICS-2026-10-19.md`).
