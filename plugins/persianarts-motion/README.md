# PersianArts Motion (Claude Code plugin)

Persian motion graphics, cooked from a pantry of themable motion ingredients.

```bash
claude plugin marketplace add AmBplus/PersianArts
claude plugin install persianarts-motion@persianarts
```

Then ask, for example: «یک موشن‌گرافیک آموزشی ۴۵ ثانیه‌ای دربارهٔ چرخهٔ آب برای دانش‌آموزان می‌خواهم».

Design and roadmap: [`docs/MOTION-SKILL-PLAN.md`](../../docs/MOTION-SKILL-PLAN.md). Status: **v0.1 — skeleton**
(stages, Persian rules, craft and sound references, schemas, Persian linter). The render engine, ingredient
catalog and `pa` CLI arrive in phase 1.
