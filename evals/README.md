# evals — خط‌کش کیفیت (پ۰)

هدف: ابزار سنجش ثابت برای مهارت موشن‌گرافیک PersianArts؛ هر نسخه با همین معیارها مقایسه می‌شود.

- `briefs/` : پنج brief ثابت (آموزشی، اطلاع‌رسانی، معرفی محصول، تیتراژ، شبکهٔ اجتماعی). هر کدام هر چهار نسبت ۹:۱۶، ۱:۱، ۴:۵ و ۱۶:۹ را می‌خواهد.
- `rubric.md` : کارت نمرهٔ ۸ معیاره با تعریف نمرهٔ ۴، ۷ و ۹.
- مرجع‌های پیشنهادی: نمونه‌های 01، 04، 13، 15، 07 (از بررسی ۱۶ نمونه).
- کالیبراسیون مالک: ۲ تا ۳ نمونه (یکی خوب، یکی متوسط، یکی بد) را با کارت نمره نمره می‌دهد؛ نمرهٔ او و بازبین مستقل باید حداکثر ۱ واحد اختلاف داشته باشند.
- بعد از کالیبراسیون، briefها ثابت می‌مانند و هر تغییر در rubric باید در دفتر کیفیت ثبت شود.
- وضعیت: پیش‌نویس کارت نسخهٔ ۲ در `evals/rubric-v2.md` است (۹ معیار؛ هنوز تأیید مالک ندارد).
